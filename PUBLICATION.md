# Publication Scope

Reviewed on October 24, 2026.

## Included

This repository contains newly written descriptions of project work and development practices, limited aggregate observations, official competition links, and fingerprints of the source records used in the review. This is an editorial documentation release, not a release of competition submissions.

The source fingerprints support traceability to an archived snapshot. They do not make the underlying records available, prove authorship, or independently reproduce a model result. Evidence files explicitly state when a claim rests on a historical report rather than a rerun.

## Excluded

Competition input records, labels, reference answers, predictions, OOF files, retrieval indexes, model weights, original source code, supplied baselines, raw conversations, infrastructure details, and team-owned material are excluded.

The agreements for [ETRI](https://dacon.io/competitions/official/236690/overview/agreement), [SCPC](https://dacon.io/competitions/official/236730/overview/agreement), [wind](https://dacon.io/en/competitions/official/236727/overview/agreement), [DeepVoice](https://dacon.io/competitions/official/236749/overview/agreement), and [procurement](https://dacon.io/competitions/official/236754/overview/agreement) contain data-security and/or platform code-sharing conditions. This documentation does not treat competition participation, model-use permission, or non-exclusive sponsor rights as permission to redistribute all assets on GitHub.

The DeepVoice and procurement agreements also contain award-related exclusive-rights conditions. I confirmed that I received neither an award document nor prize money for those two competitions. Data, dependency, and code-sharing conditions remain separate.

## Interpretation and open questions

The release scope is limited to fresh, non-sensitive descriptions; that scope is an editorial judgment, not an organizer-issued clearance. No blanket permission for GitHub source-code distribution was obtained. The relationship between platform sharing clauses and external source publication after competition close still requires clarification before a code release.

Source code, if cleared, will be added under the relevant competition folder in this repository. No per-competition repository or submodule is required. No license to third-party assets or excluded implementations is implied by these documents.
