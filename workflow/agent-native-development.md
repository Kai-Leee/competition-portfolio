# What Agent-Native Development Meant in These Projects

## Work contracts before execution

The later projects recorded the problem, baseline, evaluation conditions, permitted data, and expected artifacts before asking coding agents to implement or investigate a change. The wind project's registry and orchestration made parts of that contract executable. Its [case study](../competitions/wind-power/README.md) also preserves a failed production execution.

## Plans, implementations, runs, and judgments

These are separate claims. A skill file describes a workflow. Source code shows an implementation. A run summary records a particular execution. A review applies a judgment to evidence. None automatically proves the others.

The [ETRI review workflow](../competitions/etri-human-understanding/README.md) checked collected metrics, manifests, fold results, and logs. The [DeepVoice records](../competitions/deepvoice/README.md) linked questions and decisions back to an existing run rather than duplicating its artifacts into each summary.

## Review was specific to the project

The inspected wind smoke record demonstrates actual execution of two provider verification stages. Other repositories contain coding-agent instructions and validation records, but that does not establish the same multi-agent setup everywhere. The [procurement case](../competitions/procurement-compliance/README.md) therefore describes implementation and local checks without inventing an independent reviewer execution.

## What stayed under human responsibility

Choosing the objective, accepting a candidate, resolving rights and rules, and deciding what may be submitted or published remain separate from an agent reporting success. Agent review is not human approval. A mock output or schema-valid answer is not evidence of model accuracy.

## What I do not claim

These artifacts do not establish a measured aggregate cost saving, development-speed improvement, universal compliance, or fully autonomous research. The contribution documented here is the construction and use of inspectable work contracts, scoped execution, and preserved evidence, with failures and uncertainty left visible.
